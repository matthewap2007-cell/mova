# Security policy

## Supported versions
Only the latest release receives fixes. During the beta, that's the newest `0.x` release.

## Reporting a vulnerability
Please **don't open a public issue** for security problems, such as a file that crashes Mova in an exploitable
way, a way to make Mova read or write files you didn't choose, or a problem in the bundled FFmpeg.

Instead, use **[Report a vulnerability](https://github.com/matthewap2007-cell/mova/security/advisories/new)**
(GitHub's private reporting, under the repository's *Security* tab). Include:
- the Mova version (menu bar icon → Help & Feedback → Copy Diagnostics);
- steps to reproduce, and a sample file if you can share one safely.

You'll get a reply within 7 days. Fixed issues are credited in the release notes unless you'd rather not be named.

## Verifying downloads
Every release lists SHA-256 checksums in `SHA256SUMS.txt`. Download Mova only from this repository's Releases page.
